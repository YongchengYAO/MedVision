# `verl_utils`

Build verl-format parquet datasets for reinforcement fine-tuning, with an optional held-out test split. The per-task formatters (`_format_data_*_verl`) are private and wrapped internally; the module exposes the two `prepare_dataset_for_verl*` entry points.
